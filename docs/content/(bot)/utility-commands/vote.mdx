### Description

This command can be used to check whether your Top.gg vote is still active and to get a button that takes you to the
vote page.

Voting gives you a **20% leveling boost** for **12 hours** in every server that has vote boosted leveling enabled. While
your vote is active, the command tells you when you can vote again.

If the server you run the command in has turned vote boosted leveling off, the command will let you know. Your vote
still counts in other servers that have it enabled. Server managers can change this with the **Vote Boosted Leveling**
option of [/config toggle](../config-commands/config/toggle), as explained in the
[multipliers guide](../guides/setting-up-leveling-multipliers#toggling-vote-boosting-leveling).

### Command Structure

```
/vote
```

### Permission

- N/A **(User)**
- N/A **(Bot)**
